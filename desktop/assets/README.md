# Icons

`app-icon-1024.png` is the package-ready version of `app-icon.png`. Linux packaging uses the PNG,
while macOS packaging uses the multi-resolution `app-icon.icns` generated from it.

## Coding AI icons

These UI assets are the official product marks used by the coding-agent picker:

- `codex.webp`: Codex icon from the official OpenAI image URL supplied for this project.
- `claude.svg`: Claude icon from Anthropic's official press kit.

References: [OpenAI brand](https://openai.com/brand/) and
[Anthropic press kit](https://www.anthropic.com/press-kit).

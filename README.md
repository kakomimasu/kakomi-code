# 囲みコード

<p align="center">
  <img src="desktop/assets/app-icon.png" alt="囲みコードのアプリアイコン" width="180">
</p>

囲みマスで使う AI を、アイデアから育てて対戦へ送り出すためのデスクトップアプリです。
プログラミングにまだ慣れていなくても、同梱のサンプルを使ってすぐに始められます。作戦の改善は、Codex や Claude Code に日本語で相談できます。

[紹介ページを見る](https://ninja03.github.io/kakomi-code/) · [囲みマス公式サイト](https://kakomimasu.com/)

## できること

- サンプルの AI で、すぐに囲みマスの対戦を試せる
- 作戦ごとにバージョンを作り、思いついたアイデアを安全に試せる
- 「もっと積極的に陣地を取りたい」など、日本語のメモで Codex / Claude Code に改善を頼める
- 公式 AI を相手に、盤面を選んで練習対戦できる
- 必要になったら、画面内のソースを直接編集できる

## はじめ方

1. [Deno をインストール](https://docs.deno.com/runtime/getting_started/installation/)します。
2. このフォルダをダウンロード、または clone します。
3. macOS / Linux では `run.sh`、Windows では `run.bat` を実行します。

```sh
./run.sh
```

初回はデスクトップアプリの準備に少し時間がかかることがあります。VS Code を使う場合は、`Cmd/Ctrl + Shift + B` を押して「囲みコードを起動」を選んでも起動できます。

## 最初の対戦まで

1. アプリを開いたら、AI の名前を決めます。
2. 使うバージョンと、練習相手・盤面を選びます。最初は `none` または `a1` がおすすめです。
3. 「対戦を始める」を押します。準備ができると、対戦画面を開くリンクが表示されます。

最初はサンプルのままで問題ありません。まず一局動かしてみてから、少しずつ自分の作戦にしていくのがおすすめです。

## 作戦を育てる

「新しいバージョンを作る」で、現在の作戦をコピーして別の案を試せます。うまくいかなかったときも元の作戦は残るため、気軽に実験できます。

Codex または Claude Code を使う場合は、先にそれぞれの CLI をインストールしてログインしておいてください。アプリでコーディング AI を選び、改善したいことを日本語で入力すると、選択中の作戦を更新します。

例：

- 「序盤は自分のタイルを広げることを優先して」
- 「相手の近くでは壁を壊す判断を増やして」
- 「この作戦のねらいを説明してから、改善案を作って」

## 安心して使うために

- 作った作戦はこの PC の `versions` フォルダに保存されます。大事な作戦は別途バックアップしてください。
- アプリの設定はホームフォルダ内の `.kakomimasu-ai-starter/` に保存されます。
- 対戦にはインターネット接続が必要です。

## 困ったときは

- 起動できない場合は、Deno が正しくインストールされているか確認してください。
- Codex / Claude Code に改善を頼めない場合は、各 CLI がインストール済みでログイン済みか確認してください。
- まずは新しいバージョンを作り、サンプルのまま対戦できるか試すと原因を切り分けやすくなります。

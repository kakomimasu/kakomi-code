囲みコード
できること はじめかた GitHub へ

アイデアひとつで
対戦に参加しよう。

囲みマスを始める人のための AIコーディングツール。
あなたの作戦をすぐ対戦へ。

必要なのは Deno だけ。

できること

01

すぐに動かせる

Deno を入れたら、同梱のサンプル戦略でそのままスタート。最初から API を覚える必要はありません。

02

チャットでメッセージを送るだけ

作戦のアイデアを日本語で伝えるだけ。Codex や Claude Code と一緒に、コードを改善できます。

03

エージェントを複数管理できる

作戦ごとにエージェントを分けて保存。思いついたアイデアを並行して育て、いつでも対戦で試せます。

はじめかた

  1. 1

    Deno をインストール

    はじめての方も、公式の案内に沿って準備できます。

    ↗
  2. 2

    このリポジトリを取得

    ターミナルで次のコマンドを実行します。

    git clone https://github.com/kakomimasu/kakomi-code.git
  3. 3

    囲みコードを起動

    macOS / Linux では run.sh、Windows では run.bat を実行します。

  4. 4

    チャットで作戦を入力

    「ランダムに配置して、ランダムに移動する作戦にしよう」と送ってみましょう。

  5. 5

    「対戦を始める」をクリック

    作成したエージェントで、さっそく対戦を始められます。
